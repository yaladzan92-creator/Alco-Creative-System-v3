# AI Workflow

## Tujuan
Dokumen ini menjadi Single Source of Truth untuk alur kerja Alco Creative System.

## Prinsip Workflow
- Workflow First
- Shared Business Context
- Semua output AI dapat diedit
- AI tidak menimpa hasil edit pengguna
- Regenerate dilakukan atas permintaan pengguna
- Workflow dapat dihentikan dan dilanjutkan kapan saja

## Entry Workflow

### Mode A — Belum Memiliki Produk
Idea → Market Research → Audience → Pain Point → Market Assessment → Positioning → Offer → Marketing Angle → Campaign

### Mode B — Sudah Memiliki Produk
Existing Product → Product Analysis → Audience Confirmation → Positioning → Offer Review → Campaign

Kedua mode menghasilkan Shared Business Context yang sama.

## Shared Business Context
- Product
- Audience
- Pain Point
- Positioning
- Offer
- Marketing Angle
- Brand Foundation
- Copy Direction

Generator tidak boleh meminta ulang data yang sudah tersedia.

## Fase Workflow
### Discovery
Product, Audience, Pain Point, Market Assessment

### Strategy
Positioning, Offer, Marketing Angle

### Branding
Brand Foundation, Brand Voice, Messaging

### Campaign
Copy Ads, Image Prompt, Carousel Prompt, Video Prompt, Landing Page, Export

## Dependency Rules
Perubahan Product, Audience, Positioning, atau Offer tidak menghapus output AI, tetapi memberi status **OUTDATED** sampai pengguna memilih Regenerate.

## Manual Edit
Status:
- AI Generated
- Manual Edited
- Outdated

## Project Save
- Workflow Progress
- Shared Business Context
- AI Outputs
- Manual Edit
- Revision
