# Product Specification
Product : Alco Creative System
Status  : Draft
Version : 1.0

---

# 1. Executive Summary

Alco Creative System adalah AI Product Marketing Operating System yang membantu pengguna mengubah ide maupun produk yang sudah dimiliki menjadi campaign digital yang siap digunakan melalui workflow yang terstruktur.

Dokumen ini menjadi referensi utama (Single Source of Truth) untuk seluruh dokumentasi proyek.

---

# 2. Product Vision

Menjadi platform AI yang mempercepat proses riset, strategi, branding, dan pembuatan campaign digital sehingga pengguna dapat menghasilkan campaign profesional dengan workflow yang konsisten.

---

# 3. Product Mission

- Menurunkan learning curve digital marketing.
- Mempercepat pembuatan campaign.
- Menjaga konsistensi kualitas output AI.
- Menjadi fondasi Alco Ecosystem.

---

# 4. Target User

Primary
- Digital Marketer
- Affiliate Marketer
- Content Creator
- Solopreneur

Secondary
- Agency
- Startup
- Konsultan Marketing

---

# 5. Value Proposition

- Workflow lebih penting daripada prompt.
- Semua output berbasis Shared Business Context.
- Campaign dapat dibuat lebih cepat dengan kualitas yang konsisten.
- Seluruh output dapat diedit oleh pengguna.

---

# 7. Workflow

Mode A
Idea → Research → Strategy → Branding → Campaign

Mode B
Existing Product → Product Analysis → Strategy → Branding → Campaign

# 8. Core Principles

1. Documentation First Development
2. Workflow First
3. Shared Business Context
4. User Owns AI Output
5. Manual Regenerate
6. Outdated Dependency System
7. Modular Architecture
8. Scalability
9. Security by Design

Frontend
- React
- TypeScript
- Vite

Backend
- Express

AI
- Gemini

Storage
- Firestore

---

# 10. Business Rules

- Semua generator membaca Shared Business Context.
- Output AI tidak ditimpa otomatis.
- Perubahan data inti memberi status OUTDATED.
- Regenerate dilakukan atas persetujuan pengguna.

---

# 11. Success Metrics

- Campaign selesai dalam hitungan menit.
- Workflow dapat diselesaikan oleh pengguna baru.
- Output siap digunakan.
- Produk siap dipasarkan sebagai MVP.
