# USER_JOURNEY

## Tujuan
Menjelaskan perjalanan pengguna dari ide hingga campaign siap digunakan.

## Journey MVP
1. Login
2. Membuat Project
3. Mengisi Shared Business Context
4. Menjalankan Workflow Wizard
5. Generate AI Output
6. Review & Edit Manual
7. Generate Campaign
8. Export ZIP

## Pain Point yang Diatasi
- Tidak tahu langkah berikutnya.
- Informasi bisnis tercecer.
- Prompt tidak konsisten.

## Success Metric
- Workflow selesai tanpa bantuan eksternal.
- Campaign berhasil diekspor.
