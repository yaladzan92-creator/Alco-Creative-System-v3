# USER_PERSONA

# Persona Utama
## Solopreneur Digital

### Profil
Menjual produk/jasa sendiri dan ingin mempercepat pembuatan campaign.

### Tujuan
- Membuat strategi marketing cepat.
- Menghasilkan konten konsisten.
- Menghemat waktu.

### Pain Points
- Bingung memulai.
- Terlalu banyak tools.
- Prompt AI tidak konsisten.

### Kebutuhan
- Workflow terpandu.
- Output dapat diedit.
- Project tersimpan.

### Success Criteria
Campaign selesai dalam satu alur kerja.
