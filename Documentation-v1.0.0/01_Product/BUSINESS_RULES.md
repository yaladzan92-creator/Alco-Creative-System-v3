# BUSINESS_RULES

## Workflow
- Semua project mengikuti workflow resmi.
- Tidak boleh melewati tahap wajib.

## Authentication
- Login wajib.
- Mock auth dilarang di production.

## Ownership
- Satu project memiliki satu pemilik.
- Kolaborasi hanya melalui fitur resmi.

## AI
- AI tidak boleh menimpa hasil edit manual.
- Semua output dapat diregenerate oleh pengguna.

## Validation
- Data wajib tervalidasi sebelum disimpan.

## Export
- Export menghasilkan paket ZIP yang konsisten.

## Security
- Validasi ownership pada setiap akses data.
- API key tidak disimpan secara tidak aman.
